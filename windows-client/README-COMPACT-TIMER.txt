PisoNet Windows Client - Compact Timer

Replace your existing windows-client folder with this folder, but KEEP your own windows-client/.env file.

From windows-client run: npm install, then npm run dev.

Compact: 270 x 130 px. Add voucher: 270 x 218 px. Collapsed side tab: 54 x 82 px.

Click the right arrow to collapse, the edge tab to expand, and + Add time to redeem another voucher.

The backend must support 6-character voucher redemption and adding time.
